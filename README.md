# CS50-Projects
Description: This repository contains my projects of CS50,
I completed this entire CS5O-Introduction to Computer Science online course offered by Harvard University, which took me approximately 3 months to complete. I went through all eleven lectures from week 0 to week 10, where I learned about C and Python Programming languages. Especially, I have cleared almost all basic of python and have built some small projects on my own using python which are in my other repositories. Beside this, I got clear introduction to different tools that are useful in Computer Science field like HTML, JavaScripts, CSS, and SQL. I got know about Array, memory, Data Structure and Algorithms in introductory level.
To talk about my own experience, first two lectures were really easy and projects were also really easier than expected for beginner students like me. However, form third lecture it started to become really tough for beginner students including me, it was really tough especially problem sets were really harder than expected. Again during python weeks I felt like they were easy and understandable for every students.
To be honest, even though I went through every problem set's walkthrough a lot of time I couldn't solve some problem sets on my own, so I  took help from various social media site. Especially during 3, 4, and 5 week's problem sets. But I completed this entire course with clear introduction to computer science.
To talk about my final project, I built Volunteer and Blood donor management system with the help of python and SQLite Database in command line interface. In short, it is the replacement for paper based database system of saving information about volunteer and blood donor for small clubs or society like Junior Red Cross Society. I have included this project of mine in another repository called Portfolio you can see there.
